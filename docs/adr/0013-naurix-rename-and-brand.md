# ADR 0013 — Rename to Naurix and adopt the Aurora brand
**Status:** Accepted

**Context:** The product was named *Agent Terminal* in the first documents. The maintainer chose **Naurix** and supplied a brand sheet (`assets/brand/naurix-brand-system.png`: wave "N" mark, Aurora Purple `#8B7CFF`, Aurora Teal `#39D6C5`, Midnight `#0B1020`, Cloud White `#F4F7FF`, a sidebar-and-tabs "brand in action" mock-up, and the line "One workspace. Infinite possibilities.").

**Decisions**
1. **Rename everywhere:** product/window/menu name, bundle identifier `dev.naurix.app`, binary `naurix`, Rust crates `naurix` / `naurix-core`, database `naurix.db`, environment variables `NAURIX_*` (`NAURIX_BENCH_*`, `NAURIX_SMOKE_*`, `NAURIX_INSTALL_DIR`), docs and scripts. Only the checkout folder name (`agent-terminal-foundation`) is left, as it is outside the project's control. Earlier ADRs keep their numbers; their text uses the new name.
2. **Data is preserved:** on startup, if `dev.naurix.app` does not exist and `dev.agentterminal.app` does, the whole folder is renamed (atomic, no copying of a live SQLite/WAL file) and its `agent-terminal.db*` files become `naurix.db*`. Covered by a test (idempotent; never overwrites an existing new folder).
3. **Tokens, not hard-coded colors:** brand colors are Tailwind theme tokens in `src/index.css` (`midnight`, `surface`, `raised`, `line`, `purple`, `teal`, `cloud`, `muted`, `faint`). Primary actions use the Aurora gradient with dark text for contrast. The terminal uses the brand Midnight background and a purple cursor/selection with an ANSI palette tuned to the brand; prompt colors that use the 256-color palette (Powerlevel10k) are unaffected.
4. **Sidebar shows only what exists:** Home, Projects, Agents are live; MCP, Skills, Git and Settings are visibly disabled with a "Soon" chip, so the navigation matches the brand mock-up without claiming features that are not built.
5. **Home screen** replaces the old empty states: a terminal-style greeting ("Your terminal. Your agents. Your universe."), context-aware actions, other projects, and previous-session metadata. The aurora glow is decorative and drawn only on Home, never behind a terminal (readability and rendering cost).
6. **Window:** overlay title bar (traffic lights over the sidebar, hidden title) with the tab strip and sidebar header as drag regions; this adds the single permission `core:window:allow-start-dragging`. Tabs default to the project folder as a `~/path` (numbered when repeated), as in the mock-up.
7. **Logo assets are my vector redraw** of the mark in the brand sheet (the sheet is only 1536×1024, too small to derive a 1024 px icon). If the maintainer has the master vector, replacing `assets/naurix-mark.svg` and regenerating icons is the intended path.

**Not verified:** dragging the window by the overlay title strip (needs a human); the final terminal view was seen only through the maintainer's own session, not in an automated capture; the isolated second instance used for visual checks would not open a window with a faked `HOME`. A `NAURIX_DATA_DIR` override for isolated test runs is a worthwhile follow-up.

## Addendum — test isolation and the context menu
- **`NAURIX_DATA_DIR`** (absolute path) selects a separate data folder. The smoke and benchmark modes only run when it is set, because they create workspaces and sessions; `./run.sh sandbox` sets it (plus `NAURIX_DEV_PORT`) so a second copy can run beside your own. This was added after test-only environment variables leaked into a long-running dev instance and kept re-creating a test workspace in real data.
- **Terminal context menu** (right-click): Copy, Paste, Split Right/Left/Up/Down, Close Pane. Splits can place the new pane before or after the old one without remounting any terminal. Clipboard access is two Rust commands (`pbpaste` / `pbcopy`, fixed arguments, no shell, 1 MiB cap) called only from the menu items; no clipboard plugin dependency. Verified by driving real `contextmenu` DOM events in a sandboxed instance (menu contents, all four directions, origin pane not remounted). **Copy/Paste themselves were not exercised automatically** because that would overwrite the user's clipboard.
